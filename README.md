# 你好，我是 Infy 😎

GIS / 遥感 / WebGIS 方向的开发者。喜欢把一个完整的方法链做成**可复现、有展示力**的开源项目：从把 137 首唐诗宋词里的古地名打上地图，到用真实 DEM 沙盘推演一座湾区小城的城镇演化，再到让六个 AI 角色在真实校园里自导自演七天。

> 🌏 项目大多围绕同一个问题：**怎么让地理知识变得可玩、可看、可复现。**

Hi, I'm Infy — I build reproducible, demo-ready GIS & remote-sensing projects, from a poetry map of classical Chinese place names and a DEM-constrained town-evolution sandbox to emergent multi-agent chronicles of my campus.
