# 你好，我是 Infy 👋

GIS / 遥感 / WebGIS 方向的开发者。喜欢把一个完整的方法链做成**可复现、有展示力**的开源项目：从把 137 首唐诗宋词里的古地名打上地图，到用真实 DEM 沙盘推演家乡福鼎的城镇演化，再到给高一学生做的地理 / 化学学习站。

> 🌏 项目大多围绕同一个问题：**怎么让地理知识变得可玩、可看、可复现。**

Hi, I'm Infy — I build reproducible, demo-ready GIS & remote-sensing projects, from a poetry map of classical Chinese place names to a DEM-constrained town-evolution sandbox of my hometown.
